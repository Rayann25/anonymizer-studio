Protocole de Sécurisation d'Expurgation

Une simple boîte d'annotation CSS ne protège pas les données. En mode expurgation, le canevas applique un aplat opaque définitif détruisant les pixels sous-jacents de la signature avant export, empêchant toute récupération optique.
